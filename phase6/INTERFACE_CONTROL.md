# Pre-transfer cosmetic-output control

Initial development records raw pytest elapsed times and Python object addresses
inside otherwise identical public failure traces. Those display-only differences
can alter model prompts even when two policies select the identical evidence set.
Before freezing transfer, normalize only `object at 0x...` addresses and terminal
`in <number>s` pytest timings in reader-facing public logs. Preserve raw logs.
The harness already normalizes the isolated case directory in reader-facing logs.
Do not alter assertions, exception types, source lines, counts or test results.

Validate the control on the already-seen interpolation-precedence edit, using the
same pointwise evidence twice. Identical delivery must have identical request
hashes, and the replay must use the existing response cache. The validation does
not add training labels or modify learned parameters. This is an explicit small
interface intervention after development, before any fresh request is generated.
Later identical policy deliveries are shared physical calls, not independent
model samples; logical per-policy request/token costs are still reported.
