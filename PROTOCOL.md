## Decision and scope

SERBench's checked release measures supplied-set certificates rather than complete
repairs; MuSiQue supports complete QA but lacks continuing corrections. Neither
is adopted as a chronological experience sequence. Reuse their separation of
inference records and evaluator labels, not their rows. The new task prepares a
complete machine-readable quote using item → contract → tax references. Current
revision authority is declared, never inferred from low energy. Source values,
references and earlier quote artifacts remain accessible to every arm.

Four development histories and six fresh confirmation histories each contain an
initial quote, a repeated request after reset, a contract-value correction, a changed
item-to-contract reference and a preservation request for another item. All
identifiers and prices are generated locally. Each history has three items,
three contracts and three tax records, shuffled; revisions accumulate rather
than replacing source evidence. The history is a constructed business process,
not naturally collected user experience. Complete behavior is correct item,
quantity, integer subtotal/tax/total and current source citations. The authored
formula uses round-half-up integer tax. Evaluator expectations are derived from
the generator's private world; selectors see only requests and source records.

## Acquisition and boundaries

A small linear set energy is fitted by class-balanced logistic loss to outcomes
of actual attempted sets executed by an authored deterministic quote tool.
Labels are binary complete success, not hidden sufficient-ID certificates.
This is feedback earned by attempted tool behavior in an authored environment;
it is not feedback earned by the primary LLM. First try bounded random exploration.
If it fails, diagnose positive-outcome exposure with ordinary dependency-closure
attempts and one-record perturbations, preserving both attempts and checkpoints.
These exploration interventions are investigator-authored; charge their work.

Features expose query match, declared current status, source kinds, resolved
reference edges and whether a query-matching record has its reference in the set.
No numeric answer or evaluator fields are features. These hand-engineered
relations encode substantial task structure; representation learning is not
tested. A pointwise feature ablation diagnoses missing interactions. No neural
win is required. Persistent parameter updates are CPU arithmetic, independently
of any model-serving access.

Persistent state: source archive and revisions, past completed quote artifacts,
feature schema and fitted weights. Each request reconstructs the current index;
selection variables and reader chat context reset. Answer reuse must validate
quantity and current source lineage; code and those rules are public to all arms.
Confirmation freezes weights, code, claims and seeds before fresh generation;
no confirmation task or answer supplies acquisition feedback. The zero-weight
control identifies the contribution of acquired weights given the same authored
representation and exhaustive search. It is not the ordinary-access comparator.

## Minimal comparisons

- Ordinary access: version-aware dependency closure plus valid answer reuse,
  with the executable quote tool available. No compact evidence budget prevents
  its fallback or repair.
- Serious set-aware learned alternative: exhaustive discrete search of all
  three-record sets under the acquired score.
- Energy candidate: deterministic one-swap descent on E = -score, starting from
  a fixed pointwise heuristic, at most ten accepted moves; identical weights.
- Diagnostics: zero weights, pointwise-only fitted score, all current evidence,
  missing one required record and source-stale evidence where available.

Negative score and energy induce exactly the same ordering. The tested operational
difference is exhaustive search versus bounded local optimization, not an intrinsic
EBM property. No continuous relaxation or SPEN replication is claimed.
Candidate discovery supplies the full visible archive to every method; account
for this favorable reachability separately from selection. This phase makes no
full-repository retrieval claim.
