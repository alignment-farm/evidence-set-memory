# Phase 5 development — first preserved attempt

12 authored histories, six chronological episodes each. Native CPython output
matches independently constructed expected strings in boundary tests. There are
nine eligible current-scope sections per episode; all 512 subsets are searchable.
All policies retain source access, revision/scope rules, code and answer reuse.

The four-coefficient energy learns from actual executed development subset
attempts. Its initial explicit-cross-reference representation ignores defaults
and incorrectly treats escaped pseudo-references as dependencies. Exact search
completes 58/72 first attempts; public runtime-error repair completes 72/72.
Grammar-aware representation with otherwise unchanged learning reaches 72/72
without repair. This is investigator-authored representation engineering, not
an acquired ability to parse unfamiliar syntax.

The untrained grammar-aware control also completes 72/72, delivering 64,258 bytes
over noncached executions. Trained exact/relaxed selection delivers 36,014 bytes,
but ordinary closure only 28,704, with the same 72/72 quality. Exact/relaxed sets
match in this run; the tested relaxation does more work. Ordinary closure needs
no energy training or subset search. These numbers include 24 validated cache
hits per policy, so they are not 72 independent first-time selections.

Remaining acquisition issue: successful-but-longer attempts have fewer training
pairs than success/failure contrasts. The learned resolved-edge reward can favor
irrelevant connected sections. Next bounded diagnosis: balance the two pair
classes using the **same executed feedback**, compare compactness and complete
quality, and preserve the original unbalanced attempt. No fresh transfer data
has been generated or inspected. See `runs/development/` for raw attempts, models,
loss traces, outcomes, native costs and source/runtime hashes. The protocol and
four boundary tests are under `phase5/PROTOCOL.md` and `scripts/test_phase5_config.py`.
