# Post-hoc public-requirement repair

Declared after frozen transfer ends. The documentation audit finds that ordinary,
broad and energy-selected CLI patches omit the explicitly requested function
documentation, despite passing all native tests. Empirical reuse includes it.

Make one **ordinary reader continuation** from its saved final conversation and
source patch. Add an investigator-authored public review note identifying only the
documentation omission already observable from the request and submitted diff.
No private test names, results, expected outputs or reference docstring are provided.
Keep the reader/settings fixed; allow exactly one additional response, apply it
through the same scope/AST/exact-match boundary, then run authoritative tests and
inspect the relevant docstring. Do not rewrite frozen scores or canonical history.

This is externally reviewed repair, not autonomous self-detection, new acquisition,
fresh confirmation or an independent treatment arm. Charge the additional request,
tokens, tests and review provenance. Even if it fits within the original numerical
eight-call cap, the stopping/feedback policy differs and must remain separate.
The purpose is to distinguish an addressable public-scope omission from missing
candidate source or an incapable edit mechanism. Human review labor is unknown.
